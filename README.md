
# AVELOR — Fine Dining Restaurant

A luxury restaurant website with an elegant design, online table reservations, and an admin dashboard.

## Features
- Responsive restaurant website
- Interactive menu
- Online table reservations
- Table availability management
- Admin dashboard
- Reservation management

## Technologies
- React
- JavaScript
- CSS
- Node.js
- Express.js
- MongoDB
